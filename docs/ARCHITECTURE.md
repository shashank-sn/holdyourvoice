# Architecture

`text.ts` establishes stable sentence indices and text measurements. `hygiene.ts` inspects hidden Unicode and applies a conservative, explicit clean without scoring the writing. `voice-dna.ts` builds 13-element profiles and evaluates the explicitly automated VoiceDNA checks. `ai-editor-rules.ts` owns 143 reviewed rules restored from the published `@holdyourvoice/hyv@2.9.24` `signals.ts` artifact plus two retained 3.1 detectors. `ai-editor.ts` executes sentence- and physical-line-scoped rules under ruleset version `2.9.24-static.2`, mapping every finding back to a stable sentence. `learning.ts` stores text-free, profile-scoped verified-repair events and composes a bounded local preference list. `pipeline.ts` composes reports, produces the priority-tiered rewrite brief, and performs post-rewrite verification. `cli.ts` is the local file/stdin adapter.

`pipeline.ts` is the only scored output-composition point. It combines pass states, keeps both engine scores unchanged, and attaches hygiene as a separate non-scoring report. `finalOutputCheck` is the profile-free last-mile boundary shared by CLI and MCP: clean text passes byte-for-byte, a leading U+FEFF is removed, and unresolved hidden Unicode withholds output. A passing `verify` records local learning by default; `rewrite-prompt` reads it by default. Learning is local-only, deterministic, profile-fingerprinted, inspectable with `hyv learning show`, and bounded to ten composed preferences. It never stores draft or candidate text, calls a model, or synchronizes. The restored catalog also stays local: no 2.9 hosted analysis, telemetry, authentication, profile sync, provider calls, automatic file mutation, or whole-draft rewriting entered the engine. The only file-mutating command is explicit `hyv hygiene --fix`; it writes a new path and refuses to overwrite the input or an existing output. Rewrite preparation remains limited to flagged sentence IDs, so clean and unflagged text is preserved.

Add an AI Editor rule in `ai-editor-rules.ts` with positive and negative tests and a documentation entry. Add a VoiceDNA signal in `voice-dna.ts` with an auditable explanation. The [prompt contract](PROMPT-CONTRACT.md) owns tier ordering; changing the priority above preservation requires a contract and test update.
