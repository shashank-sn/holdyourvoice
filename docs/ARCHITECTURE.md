# Architecture

`text.ts` establishes stable sentence indices and text measurements. `hygiene.ts` inspects hidden Unicode and applies a conservative, explicit clean without scoring the writing. `voice-dna.ts` builds version 2 profiles, evaluates both profile versions, and reports version 3 fingerprint drift. `ai-editor-rules.ts` owns the stable deterministic catalog. `ai-editor.ts` executes sentence- and physical-line-scoped rules under ruleset version `3.2.0-reconciled.1`, then applies profile policy without changing rule IDs. `pipeline.ts` derives edit eligibility from structured blocking findings; advisory and pending-judgment findings cannot grant edit scope. `rewrite-task.ts` owns the versioned sentence-replacement and range-edit task boundary. `judgment-task.ts` reduces pre-edit SHIP/EDIT/REBUILD recommendations and post-candidate clearance. `rebuild-task.ts` prepares whole-document rebuild only after an upstream REBUILD recommendation, a CopySpec, and a signed `hyv.rebuild-authorization` capability. `semantic-review.ts` reduces immutable semantic and human-review lifecycle artifacts. `approval-capability.ts` verifies canonical Ed25519 capabilities, while `approval-context.ts` loads permission-checked trust roots and evaluator authorization. `lifecycle-adapter.ts` is the shared core-to-CLI/MCP boundary. `learning.ts` stores text-free, stable-profile-scoped events and composes a bounded local preference list. `cli.ts` and `mcp.ts` are the local adapters.

`pipeline.ts` is the only scored output-composition point. It combines pass states, keeps both engine scores unchanged, and attaches hygiene as a separate non-scoring report. `finalOutputCheck` is the profile-free last-mile boundary shared by CLI and MCP: clean text passes byte-for-byte, a leading U+FEFF is removed, and unresolved hidden Unicode withholds output. Verification is read-only; `rewrite-prompt` reads only explicit or separately approved learning. Learning is local-only, deterministic, inspectable with `hyv learning show`, and bounded to ten composed preferences. Profile v3 history is keyed by stable local identity; revision compatibility and authority decide which events become active guidance. It never stores draft or candidate text, calls a model, or synchronizes. The restored catalog also stays local: no 2.9 hosted analysis, telemetry, authentication, profile sync, provider calls, automatic draft mutation, or whole-draft rewriting entered the engine. Commands write files only through named output or learning operations. `hyv hygiene --fix` refuses to overwrite its input or an existing output, and lifecycle capability input is accepted only through stdin or a permission-checked file. Rewrite preparation remains limited to flagged sentence IDs, so clean and unflagged text is preserved.

Add an AI Editor rule in `ai-editor-rules.ts` with positive and negative tests and a documentation entry. Add a VoiceDNA signal in `voice-dna.ts` with an auditable explanation. The [prompt contract](PROMPT-CONTRACT.md) owns tier ordering; changing the priority above preservation requires a contract and test update.
