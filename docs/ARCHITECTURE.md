# Architecture

`text.ts` establishes stable sentence indices and text measurements. `voice-dna.ts` builds 13-element profiles and evaluates the explicitly automated VoiceDNA checks. `ai-editor.ts` owns the public deterministic ruleset. `learning.ts` stores text-free, profile-scoped verified-repair events and composes a bounded local preference list. `pipeline.ts` composes reports, produces the priority-tiered rewrite brief, and performs post-rewrite verification. `cli.ts` is the local file/stdin adapter.

`pipeline.ts` is the only output-composition point. It combines pass states and keeps both engine scores unchanged. A passing `verify` records local learning by default; `rewrite-prompt` reads it by default. Learning is local-only, deterministic, profile-fingerprinted, inspectable with `hyv learning show`, and bounded to ten composed preferences. It never stores draft or candidate text, calls a model, or synchronizes. Add an AI Editor rule in `ai-editor.ts` with a test and documentation entry. Add a VoiceDNA signal in `voice-dna.ts` with an auditable explanation. The [prompt contract](PROMPT-CONTRACT.md) owns tier ordering; changing the priority above preservation requires a contract and test update.
