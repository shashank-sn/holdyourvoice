# architecture

`text.ts` provides sentence and word measurements. `voice-dna.ts` builds and evaluates profiles. `ai-editor.ts` owns the deterministic rules. `rewrite-task.ts` owns versioned sentence-replacement tasks. `semantic-review.ts` and `lifecycle-adapter.ts` reduce immutable semantic and human-review transitions. `approval-capability.ts` verifies signed approvals against the permission-checked context loaded by `approval-context.ts`. `learning.ts` stores text-free, stable-profile-scoped events and composes bounded local preferences. `pipeline.ts` is the only scored output-composition layer: it combines pass states but never changes either engine score. `cli.ts` and `mcp.ts` expose the shared core while keeping verification read-only and learning explicit or separately approved.

there is no hosted API, telemetry path, account boundary, payment flow, or runtime network request in the core path. an editor or model receives the generated brief outside this package. the optional Claude Desktop extension is a local stdio MCP adapter around the same engine; it does not create a hosted path.
