# contributing

read the repository [contributing guide](https://github.com/shashank-sn/holdyourvoice/blob/main/CONTRIBUTING.md). add a rule only with a stable ID, severity, reason, repair direction, public provenance, counterexamples, and regression tests. exclude client text, private prompts, secrets, embeddings, analytics, and network paths.

small changes that make the local boundary clearer are welcome.
