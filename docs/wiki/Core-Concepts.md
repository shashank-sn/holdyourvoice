# core concepts

VoiceDNA asks whether a draft resembles observable mechanics in local samples. AI Editor asks whether a sentence matches one small, configured editorial pattern. their scores never average together.

A WritingBrief is optional local context for audience, intent, format, vocabulary, and explicit prohibited terms. It activates editorial format checks without changing VoiceDNA measurements, profile storage, or the default analysis result. Batch analysis separately catches exact repeated opening and closing sentences across a local set of drafts.

the combined `passed` value is logical AND. verification adds two safeguards: no new red finding and at least 70 lexical preservation. this makes the decision visible instead of hiding it behind a single quality score.

the tool is a gate around an editor or a model you choose. generation happens outside the package.
