# privacy and data rights

samples, drafts, profiles, and candidates stay on the machine running the CLI. the repository excludes user profiles, client text, feedback history, embeddings, access tokens, private prompts, and private datasets.

only commit material you have the right to share. a profile aggregates vocabulary and preferences, so treat it as sensitive even though it is JSON. use synthetic or rights-cleared fixtures, and document provenance when a contribution includes text.
