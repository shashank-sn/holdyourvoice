# hold your voice 4.0.0

hold your voice 4.0.0 rebuilds the local writing workflows around clearer responsibilities. analysis, editing briefs, candidate verification, and approval transitions now have separate owners. the cli and mcp server still use the same local checks.

a new word economy review asks the editor to make every word earn its place before final verification. cut a phrase only when meaning, evidence, clarity, and voice survive. preserve necessary uncertainty, attribution, emphasis, and rhythm. this is editorial judgment within the authorized edit scope, with no word-count target or automatic quality score.

profile building shares measured writing data with voice analysis. fact checks index source evidence once. editing responses use explicit version validators, and learning mutations share one path for locks, receipts, and failures. the readme now explains the full product and its approval boundaries.

the compatibility work covers existing commands, mcp schemas, production imports, profile formats, saved learning, signed approvals, and portable agents. before the word economy addition, 17,783 baseline comparisons passed and all 381 tests passed on node 20, 22, and 26. the updated briefs intentionally change prompt text and task fingerprints; the final suite adds coverage for the new review and protected edit scopes. independent review found one profile-validation edge case; it was fixed and rechecked.

this release keeps the rules, schemas, prompt contracts, fixtures, and small primitives that already express their job clearly. production source lines increased from 7,633 to 7,805 as dense flows became explicit functions. production typescript bytes fell from 494,621 to 493,058. there is no claim of a large code reduction.

the npm package excludes 50 compiled development tests. those tests remain in the repository, and every production module path remains available.

existing profiles need no migration. prepare fresh version-bound tasks and approvals after upgrading: verification artifacts include the package version. hyv continues to run locally without model calls, accounts, telemetry, or automatic publication.

once version 4.0.0 is published, install it with:

```bash
npm install --global @holdyourvoice/hyv@4.0.0
```

passing checks provide bounded compatibility evidence. they do not prove writing quality, authorship, factual truth, or the absence of every possible defect.
